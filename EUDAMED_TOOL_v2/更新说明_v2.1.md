## 📋 EUDAMED Bulk Upload规范分析

### 官方文档分析结果

根据EUDAMED官方文档（https://webgate.ec.europa.eu/eudamed-help/en/data-exchange/bulk-uploading-downloading/bulk-upload.html），bulk upload采用**两步上传流程**：

**Step 1**: 上传XML请求文件（XML request payload file）
**Step 2**: 上传附件ZIP包（仅在有附件时）

### 对于UDI设备批量注册

✅ **当前工具设计完全正确**

- UDI设备信息全部包含在XML文件中
- 不需要额外附件（技术文档、标签图片等）
- 只需在EUDAMED Step 1上传生成的XML文件即可
- Step 2可以跳过

### ZIP包的使用场景

ZIP包仅用于以下场景：
1. 需要上传技术文档（如IFU、技术规格书）
2. 需要上传产品标签图片
3. 需要上传其他支持文档

在这些场景中：
- XML中需要使用`<FileName>`和`<FileURI>`标签引用附件
- 将XML和附件打包成ZIP文件
- 在EUDAMED Step 2上传ZIP包

## 🚀 使用说明

### 标准使用流程（无附件）

1. **填写Excel模板**
   ```
   打开 templates/EUDAMED_Template_v2.xlsx
   按照字段说明填写产品信息
   ```

2. **运行转换工具**
   ```bash
   # Windows用户
   双击 convert.bat
   
   # 命令行用户
   python eudamed_converter_v2.1.py --input templates/EUDAMED_Template_v2.xlsx
   ```

3. **上传到EUDAMED**
   ```
   登录EUDAMED系统
   进入 Data transfer → Bulk Upload
   点击 New upload
   选择服务类型（如DEVICE.POST）
   Step 1: 上传生成的XML文件
   Step 2: 跳过（无附件）
   点击 Go to upload management
   等待处理完成
   下载响应XML查看结果
   ```

### 高级使用（包含附件）- 手动方式

如果需要上传附件：

1. **准备附件文件**
   ```
   创建附件目录，如 attachments/
   将文档、图片等放入目录
   ```

2. **生成XML文件**
   ```bash
   python eudamed_converter_v2.1.py --input templates/EUDAMED_Template_v2.xlsx
   ```

3. **手动创建ZIP包**
   ```bash
   # 将XML和附件打包
   zip -r upload_package.zip eudamed_upload_*.xml attachments/
   ```

4. **上传到EUDAMED**
   ```
   Step 1: 上传XML文件
   Step 2: 上传ZIP包
   ```
